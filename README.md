# Online Notepad — GitHub Pages

এই প্রজেক্টটি GitHub Pages-এ চালানোর জন্য প্রস্তুত করা হয়েছে।

## প্রকাশ করার নিয়ম

1. GitHub-এ একটি নতুন **Public repository** তৈরি করুন।
2. এই ফোল্ডারের `index.html`, `README.md` এবং `.nojekyll` ফাইল repository-র মূল (root) অংশে আপলোড করুন।
3. Repository → **Settings** → **Pages** খুলুন।
4. **Deploy from a branch** নির্বাচন করুন।
5. Branch হিসেবে `main` এবং folder হিসেবে `/ (root)` নির্বাচন করে **Save** করুন।
6. কিছুক্ষণ পর GitHub Pages-এর দেওয়া ওয়েব ঠিকানায় অ্যাপটি খুলুন।

## গুরুত্বপূর্ণ

- `index.html`-এ মূল পেজের কিছু CSS/JavaScript ও ছবি `onlinenotepad.io`-এর সার্ভার থেকে লোড হয়। তাই ইন্টারনেট সংযোগ প্রয়োজন এবং ওই সার্ভারের ফাইল/নীতিতে পরিবর্তন হলে কিছু অংশ কাজ নাও করতে পারে।
- Auto Save এই সংস্করণে একই ব্রাউজারের Local Storage-এ হয়। এটি GitHub বা ক্লাউডে স্বয়ংক্রিয়ভাবে ডাটা সংরক্ষণ করে না।
- ব্রাউজারের ডাটা/সাইট ডেটা মুছে ফেললে Local Storage-এর নোট হারাতে পারে। গুরুত্বপূর্ণ নোট আলাদা করে Export/Download বা কপি করে ব্যাকআপ রাখুন।
